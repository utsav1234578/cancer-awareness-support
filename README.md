# Cancer Awareness & Support 🌸

A beautiful, fully responsive single-page website for cancer awareness and support, built with pure HTML, CSS, and JavaScript.

## ✨ Features

- 🎨 **Modern UI/UX** - Vibrant color scheme with smooth animations
- 📱 **Fully Responsive** - Works perfectly on all devices
- 📝 **Contact Form** - Client-side validation with JSON data storage
- 💬 **Real-Time Quotes** - 10 inspirational quotes rotating every 10 seconds
- 📊 **Statistics Section** - Animated counters showing impact
- 💭 **Testimonials** - Rotating testimonials from survivors
- 📚 **Resources Section** - Comprehensive health resources
- 📧 **Newsletter Signup** - Email subscription form
- ⬆️ **Back to Top** - Smooth scroll navigation
- 📈 **Scroll Progress** - Visual progress indicator

## 🚀 Quick Start

### Local Development

1. **Clone the repository:**
   git clone https://github.com/utsav1234578/cancer-awareness-support.git
   cd cancer-awareness-support
   
2. **Open in browser:**
   - Simply open `index.html` in your web browser
   - Or use a local server:
     
     # Using Node.js
     node server.js
     
3. **View the site:**
   - Navigate to `http://localhost:3000` (Node.js)
